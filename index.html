finance-channel uploader

finance-channel uploader는 지갑브리핑 운영자가 자기 채널을 관리하려고 쓰는 내부 도구입니다. YouTube API 서비스를 통해 아래 작업을 합니다.

  • 운영자 채널에 영상 업로드와 공개 예약
  • 제목·설명·태그·썸네일 수정, 공개 상태 변경
  • 운영자 채널의 댓글 작성·답글, 재생목록 관리
  • 조회수·시청 지속 시간 같은 채널 성과 분석

이 도구는 일반 사용자에게 제공되지 않으며, 운영자 본인의 Google 계정으로만 로그인합니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.

finance-channel uploader is an internal tool used only by the operator of the 지갑브리핑 channel to upload and manage videos, comments, playlists and analytics on the operator's own YouTube channel through the YouTube API Services. It is not offered to the public.
