개인정보처리방침

시행일: 2026년 10월 17일

이 방침은 지갑브리핑 운영자가 자기 유튜브 채널을 관리하려고 쓰는 내부 도구 finance-channel uploader(이하 "이 도구")가 Google 사용자 데이터를 어떻게 다루는지 설명합니다. 이 도구는 일반 사용자에게 제공되지 않으며, 운영자 본인의 Google 계정으로만 로그인합니다.

1. 이 도구는 YouTube API 서비스를 사용합니다

이 도구를 쓰는 것은 YouTube 서비스 약관에 동의하는 것입니다. Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

2. 접근하는 데이터와 권한

운영자가 승인한 아래 권한으로 운영자 본인의 유튜브 채널 데이터에만 접근합니다.

  • youtube.upload — 운영자 채널에 영상 업로드
  • youtube.force-ssl — 운영자 채널의 영상 정보(제목·설명·태그·썸네일·공개 상태), 댓글, 재생목록 관리
  • youtube.readonly — 운영자 채널과 영상 목록 읽기
  • yt-analytics.readonly — 운영자 채널의 조회수·시청 지속 시간 등 성과 지표 읽기

3. 데이터를 쓰는 목적

  • 운영자가 만든 영상을 업로드하고 공개 일정을 정하기
  • 영상 정보와 썸네일을 고치고, 고정 댓글·답글을 달고, 재생목록을 정리하기
  • 어떤 영상이 잘 보였는지 분석해 다음 영상 기획에 쓰기

위 목적 외에는 쓰지 않습니다. 광고, 프로필 작성, 판매에 쓰지 않습니다.

4. 시청자 댓글

운영자 채널에 공개로 달린 댓글을 읽어 답글을 다는 데 쓸 수 있습니다. 답글 작성에 필요한 범위에서 댓글 내용이 운영자 PC에 저장될 수 있으며, 그 밖의 용도로 쓰거나 다른 곳에 넘기지 않습니다.

5. 저장과 보관

로그인 권한(토큰)과 분석 결과는 운영자 개인 PC에만 저장됩니다. 이 도구는 이 데이터를 별도 서버에 올리지 않습니다. 운영자가 더 이상 필요 없다고 판단하면 PC에서 지웁니다.

6. 제3자 제공

Google 사용자 데이터를 제3자에게 팔거나 넘기지 않습니다. 법령에 따라 요구되는 경우는 예외입니다.

7. Google API 서비스 사용자 데이터 정책 준수

이 도구가 Google API로 받은 정보를 쓰거나 다른 앱으로 옮기는 일은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

8. 권한 철회

이 도구에 준 권한은 언제든 Google 계정 보안 설정의 '서드 파티 앱 및 서비스'에서 철회할 수 있습니다.

9. 방침 변경

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다.

10. 문의

유튜브 지갑브리핑 채널로 문의해 주세요.

Privacy Policy (English summary)

finance-channel uploader is an internal tool used only by the operator of the 지갑브리핑 YouTube channel. It uses the YouTube API Services; by using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

With the scopes youtube.upload, youtube.force-ssl, youtube.readonly and yt-analytics.readonly, it accesses only the operator's own channel to upload videos, edit video metadata and thumbnails, manage comments and playlists, and read channel analytics. Tokens and analytics results are stored only on the operator's personal computer and are not uploaded to any server. Google user data is not sold or shared with third parties, and is not used for advertising.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time via Google security settings.
